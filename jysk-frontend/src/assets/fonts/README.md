# Fixel

Шрифт макета TALO. Розробники — [MacPaw](https://fixel.macpaw.com/) у співпраці з AlfaBravo.

Ліцензія: SIL Open Font License 1.1 (повний текст — `OFL.txt`).
Джерело завантаження: <https://fonts.macpaw.com/fonts/FixelAll.zip>

З повного набору (36 woff2) у репозиторій покладені лише ті накреслення,
що реально використовуються, щоб не роздувати вагу:

| Файл                          | Роль                          | font-weight |
| ----------------------------- | ----------------------------- | ----------- |
| `FixelText-Regular.woff2`     | основний текст                | 400         |
| `FixelText-Medium.woff2`      | акценти, підписи              | 500         |
| `FixelText-SemiBold.woff2`    | назви товарів, кнопки         | 600         |
| `FixelText-Bold.woff2`        | сильні акценти, ціни          | 700         |
| `FixelDisplay-Bold.woff2`     | заголовки секцій              | 700         |
| `FixelDisplay-ExtraBold.woff2`|hero-заголовки                 | 800         |

Text — для інтерфейсу й дрібного кегля, Display — для великих заголовків
(так само, як розділено в макеті).
